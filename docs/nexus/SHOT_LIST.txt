SCREENSHOTS FOR THE NEXUS GALLERY
=================================
Each slot below has a ready-made caption overlay (transparent PNG) in images/overlays/.
You only take the screenshot:

  1. Take it in game at 1920x1080 or larger (16:9). Hide the F7 window unless the shot is about it.
     The overlay darkens the bottom ~280 px and puts a small badge in the top-right corner, so keep
     the important part of the picture in the middle and the top half.
  2. Save it as  docs/nexus/art/screenshots/<slot>.png  (or .jpg), e.g. screenshots/01_crew.png
  3. Run:  python -I docs/nexus/art/make_art.py compose
     -> images/gallery_<slot>.png (screenshot + caption), ready to upload.
  To change a caption, edit GALLERY in make_art.py and run it without "compose".
